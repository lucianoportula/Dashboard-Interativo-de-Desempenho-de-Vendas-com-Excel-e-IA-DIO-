Controle de Vendas Interativo - Projeto Port 📊

Este repositório contém o projeto de uma **Planilha Inteligente de Controle de Vendas** desenvolvida no Excel, estruturada com o auxílio de Inteligência Artificial. O projeto foi criado como parte prática do curso **Santander Excel com IA e Claude**, oferecido em parceria com a **DIO (Digital Innovation One)**.

O objetivo principal é fornecer uma ferramenta prática, dinâmica e visual para a gestão de vendas multifiliais, permitindo o acompanhamento de metas, vendedores e desempenho comercial em tempo real.

 Funcionalidades do Projeto

- Estrutura Multifilias: Controle integrado simulando 3 lojas físicas distintas.
- Gestão de Equipes: Acompanhamento individual de performance para 3 vendedores por loja (totalizando 9 vendedores cadastrados).
- Tabelas Interativas & Dinâmicas: Organização automatizada de dados para facilitar a filtragem por período, filial ou colaborador.
- Foco em Tomada de Decisão: Criação de um ambiente prático voltado para insights comerciais rápidos (Dashboards/Gráficos).

 Tecnologias e Metodologias Utilizadas

- Microsoft Excel: Fórmulas, formatação condicional e tabelas dinâmicas.
- Engenharia de Prompts (IA): Utilização de modelos de inteligência artificial (Claude) para otimização da lógica das tabelas e estruturação do controle de dados.
- Boas Práticas de Organização: Separação clara entre bases de dados brutas e relatórios visuais.

 Estrutura do Repositório

- `/src` ou raiz: Contém o arquivo `.xlsx` do projeto estruturado.
- `README.md`: Documentação explicativa do projeto.

 Sobre o Curso
Este projeto faz parte do bootcamp focado em elevar o uso de planilhas tradicionais ao próximo nível através de Inteligência Artificial, unindo a robustez do Excel com a eficiência do design de dados assistido por IA.
